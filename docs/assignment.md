## Технологии

Обязательные: Git, TypeScript, Node.js, NestJS, Prisma, GraphQL, Docker.

PostgreSQL также указан работодателем в рабочем стеке.

Приложение должно предоставлять Apollo Sandbox.

## Данные и API

Визитка содержит:

- Профиль: имя, краткое описание, ссылки на GitHub/LinkedIn или другие профессиональные ресурсы.
- Навыки.
- Опыт работы: компания, должность, период, достижения.
- Проекты: название, ссылка на проект или репозиторий.

При запуске база автоматически подготавливается и заполняется данными кандидата.

API позволяет получить профиль вместе со связанными навыками, опытом работы и проектами одним GraphQL-запросом.

Использовать только подтверждённые данные кандидата и актуальное резюме. Не выдумывать профессиональные ссылки, навыки, стаж и достижения.

## Архитектура и документация

Структуру API, базы данных и архитектуру выбрать самостоятельно. Обосновать решения в README.

Разумно разделить бизнес-логику, работу с данными и GraphQL API.

## Критерии оценки и готовности

- Инженерные решения и их обоснование.
- Вложенные GraphQL-запросы и оптимизация обращений к базе данных.
- Корректное взаимодействие с базой данных.
- Автоматическая инициализация и seed.
- Читаемость и поддерживаемость кода.
- Корректный запуск с нуля по инструкции.

Количество кода не является главным критерием.
